# Barber Ecosystem — PWA Beta

## تشغيل النسخة
- افتح GitHub Pages بعد تفعيله من Settings → Pages → Deploy from a branch → main / root.
- أو شغّل محلياً عبر خادم static (مثل `python -m http.server 8000`) وافتح `http://localhost:8000`.
- يمكن تثبيت التطبيق من المتصفح عندما يكون منشوراً عبر HTTPS.

## ما تتضمنه Beta 0.2
- لوحة تحكم عربية RTL متجاوبة.
- حجوزات: إضافة، بحث، تصفية، وتغيير الحالة.
- بيانات زبائن وحلاقين وخدمات.
- عرض هيكل المؤسسة والمحلات والفروع والاشتراك.
- صفحات أولية للتسويق والولاء.
- حفظ بيانات الحجوزات محلياً في المتصفح وPWA manifest/service worker.

## قيود معروفة
هذه نسخة Frontend تجريبية فقط. لا تتضمن Supabase/Auth/RLS أو مزامنة بين الأجهزة أو دفعاً أو إرسال إشعارات/حملات حقيقية. بيانات المؤسسة والفروع والحلاقين أمثلة ثابتة. لا تستخدمها لإدارة بيانات عملاء حقيقية.

## مبادئ المنتج المعتمدة
Organization → Shops → Branches. الاشتراك مركزي للمؤسسة؛ المحلات/الفروع الإضافية بنود مدفوعة. يمكن للزبون إلغاء الحجز في أي وقت مع تحذير خلال آخر 90 دقيقة؛ ويمكن للمدير إلغاء أي حجز. يمنع الحجز النشط الثاني للزبون. هذه القواعد تحتاج إعادة تطبيق والتحقق منها على الخادم قبل إطلاق متعدد المستخدمين.
